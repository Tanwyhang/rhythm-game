# rhythm-game

**Yugen** 🎶 - *A Python Rhythm Game Inspired by osu!*  

**Description**  
Yugen is a simple Python rhythm game where you tap along to the beat! Inspired by osu!, this game lets you hit notes in sync with music, score points based on timing accuracy, and track high scores. Try different difficulty levels to challenge your rhythm skills.

**Features**  
- 🎼 Load custom songs & beat maps  
- 🔥 Instant feedback & scoring  
- 🏆 High score tracking  
- 🎮 Multiple difficulty levels  

**Get Started**  
Clone the repo, load a song, and get in sync with the beat! Contributions welcome.
